# 🚀 AI Interviewer

AI-powered mock interview platform that simulates real technical interviews using AI-based question generation and automated code evaluation.

---

## 🔥 Features

- 🎤 AI-generated technical interview questions
- 💻 Code submission and automated evaluation
- 📊 Structured feedback and scoring
- 🔄 Real-time interaction
- 🧠 Intelligent response analysis
- 📁 Session management

---

## 🛠 Tech Stack

### Frontend
- Next.js
- React
- TypeScript

### Backend
- Node.js
- Express.js
- TypeScript

- OpenAI API (GPT-4o)

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shivansh987654321/AI_Interviwer1.git
cd AI_Interviwer1
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside backend folder:

```
OPENAI_API_KEY=your_openai_api_key_here
MONGODB_URI=your_mongodb_uri_here  # Optional: required only for database persistence
```

Run backend:

```bash
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at:

```
http://localhost:3000
```
